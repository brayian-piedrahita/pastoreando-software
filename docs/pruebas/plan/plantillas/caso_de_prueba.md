# Formato de caso de prueba

| Campo | Valor |
|---|---|
| Nombre del proyecto | Pastoreando |
| Número de caso | CP-___ (consecutivo) |
| Nombre del caso de prueba | |
| Requisito asociado | RF__ / RNF__ |
| Fecha de revisión | AAAA-MM-DD |
| Descripción | Tipo de prueba, cómo se ejecuta y con qué fin |
| Ambiente o entorno | Versión, sistema operativo, navegador o dispositivo, servidor y base de datos |
| Herramienta utilizada | pytest, Vitest, JUnit, Postman, Apache JMeter, manual |
| Autor del caso | |
| Precondiciones | Datos y estado del sistema antes de empezar |
| Datos de entrada | |
| Pasos | 1. 2. 3. |
| Salida esperada | Resultado esperado según el requisito |
| Salida obtenida | Resultado real de la ejecución |
| Resultado | Aprobado / En seguimiento / Rechazado |
| Seguimiento | Código del defecto (DEF-___) si el resultado no fue el esperado |
| Severidad | Alta / Media / Baja, solo si hubo falla |
| Evidencia | Captura, archivo de resultados o salida de consola que respalda el resultado |
| Firma de aprobación | Nombre y firma de quien realizó la prueba |
